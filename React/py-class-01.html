What happens when you run python main.py?

📄main.pyYour source code
→
🔧CompilerChecks syntax, compiles
→
📦Bytecode.pyc in __pycache__
→
🧠PVMPython Virtual Machine runs it line by line
→
🖥️OutputHello, World!

A live translator at a meeting: they translate and speak one sentence at a time. If sentence 5 has a mistake, sentences 1–4 were still spoken. That's why a Python error can appear halfway through a run.

Is Python compiled or interpreted?

Both. Source is first compiled to bytecode, then the bytecode is interpreted by the PVM. We call it an "interpreted language" because there's no separate build step you run yourself. (CPython is the standard implementation; PyPy uses a JIT.)

🏷️ 15–35 min

Variables are name tags, not boxes

This one idea explains half of all Python interview "trick" questions.

Build suspense: "Most tutorials say variables are boxes. In Python that's slightly wrong, and interviewers know it."
Variables

A variable is a label stuck on an object

  • No let, no int: just name = value
  • Dynamic typing: the object has a type, the tag doesn't. x = 5 then x = "five" is fine.
  • Every object has an identity: id(x) (its address in memory)

At the airport, your suitcase gets a luggage tag. The tag isn't the suitcase. You can put two tags on one suitcase, and if someone opens it through either tag, they see the same clothes.

Naming (PEP 8): use snake_case like total_marks. Names can't start with a digit, can't contain spaces or -, and are case-sensitive (Age ≠ age).

10 / 2 → 5.0: / always returns a float.

-7 // 2 → -4, not -3! Floor means "towards minus infinity".

-7 % 3 → 2. In Python the remainder takes the sign of the divisor.

"Hi" * 3 → "HiHiHi": strings can be repeated.

7 slices, 2 friends: 7 // 2 = 3 slices each, and 7 % 2 = 1 slice left over for you.

-7 // 2 is a genuine interview trick. Use % to explain even/odd checks (n % 2 == 0).
Comparison & logic · interview favourite

== vs is, and and / or / not

Identical twins look the same (== is True), but they are two different people (is is False).

Checks Use it for
== Same value? Almost everything
is Same object (same id)? x is None

Short-circuit: and stops at the first falsy value, or stops at the first truthy value, and both return that value, not just True/False. So name or "Guest" is a handy default.

Strings

A string is a sequence of characters

📍 Indexing starts at 0
and negative indexes count from the end: -1 is the last character.

🔒 Strings are immutable

city[0] = "K" → TypeError: 'str' object does not support item assignment. Make a new string instead: "K" + city[1:]

A string is a train: each coach (character) has a number. You can look into any coach, but you can't swap a coach while the train is running. You build a new train.

Emphasise immutability: it connects back to the data-types slide and is asked in interviews.

🎯 Interview corner · 78–90 min

Questions you will be asked

Ask the question, let students answer out loud, then click to reveal the model answer.

What are the key features of Python?

Interpreted, dynamically typed, high-level, object-oriented (and supports functional style), huge standard library, cross-platform, open source, readable syntax with indentation.

What is the difference between is and ==?

== compares values (calls __eq__). is compares identity (same object in memory, same id()). Use is only for None, True, False.

Mutable vs immutable: give examples.

Mutable objects can change in place: list, dict, set. Immutable can't: int, float, str, tuple, bool, frozenset. "Changing" an immutable creates a new object.

What is the difference between / and //?

/ is true division and always returns a float (7/2 = 3.5). // is floor division, rounding towards minus infinity (7//2 = 3, -7//2 = -4).

What is PEP 8?

Python's official style guide: 4-space indentation, snake_case for variables/functions, PascalCase for classes, max ~79 chars per line, spaces around operators.

Is Python dynamically typed? What does that mean?

Yes. Types are checked at runtime and belong to objects, not variables. The same name can point to an int and later a str. (It is also strongly typed: "1" + 1 is an error, not "11".)

How do you reverse a string?

s[::-1] (slicing with step -1). Alternative: "".join(reversed(s)).

What is None?

A special singleton object of type NoneType meaning "no value". Functions without return return None. Check it with x is None.

Pick students at random (call names). Encourage short, structured answers: definition → example → one extra detail. That's how to impress an interviewer.

Watch out

Common beginner mistakes 🚧

Wrong indentation

  print("hi")

IndentationError: unexpected indent. Indent only inside blocks.

Forgetting input() is a str

age = input(); age + 1

TypeError. Use int(input()).

true / none in lowercase

is_ok = true

NameError. It's True, False, None.

Joining str and int

"Age: " + 21

TypeError. Use f"Age: {21}" or str(21).

Using = instead of ==

if marks = 35:

SyntaxError. = assigns, == compares.

Expecting methods to change a str

name.upper()

Strings are immutable: write name = name.upper().
