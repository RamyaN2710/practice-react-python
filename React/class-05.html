Concept · 05–15 min

What are props? 🎁

Props (short for properties) are values a parent passes to a child component.

  • They look like HTML attributes: <StudentCard name="Arun" />
  • The child receives them as an object: { name: "Arun" }
  • Same component + different props = different output
  • Just like arguments to a JavaScript function
☕

The chai stall order

The chai stall has one recipe and one kettle. But every customer orders differently:

"One cutting chai, less sugar." "One ginger chai, extra strong."

The recipe is the component. The order (sugar, ginger, strength) is the props.

  • Ask: "In HTML, what does <img src="cat.png"> do?" src is an attribute that changes what the img shows. Props are the same idea for our components.
  • Relate to functions: greet("Arun") vs <Greet name="Arun" />.

How props travel

Props flow one way: parent → child ⬇️

👨App (parent)<StudentCard name="Arun" />
→
📦props object{ name: "Arun" }
→
🧒StudentCard (child)shows {name}
💰

Pocket money

Parents give pocket money to the child. The child uses it, but the child can't send money up by changing the parent's wallet.

Props work the same way: data goes down from parent to child, never back up.

Want to see the props object? Add console.log(props) inside the child. You'll see { name: "Arun", course: "React" } in the console. Try it on the next playground!

"One-way data flow" is a big React idea. We'll see in Class 16 how a child can ask the parent to change something (by calling a function the parent passed down).
Types of props · 15–25 min

Passing strings, numbers and arrays 🔢

Simple rule: text goes in quotes, everything else goes in curly braces.

Type How to pass Use inside
String name="Sneha" {name}
Number age={20} {age + 1} → 21
Array skills={[...]} {skills.join(", ")}
Boolean isHosteller={true} {isHosteller ? "Yes" : "No"}

age="20" is the text "20", not the number 20. Then age + 1 gives "201" 😅. Numbers need braces: age={20}.

The "201" trick is memorable: try it live on the next playground. We'll learn to show arrays as proper lists with map() in Class 9. For now, join(", ") is enough.
Destructuring

Destructuring: unpack the props parcel 📦

📦

Opening a Flipkart parcel

The props object is a parcel. With props.name you reach into the box every single time.

Destructuring { name, course } unpacks the parcel once and puts each item on the table, ready to use.

  • Click through the tabs. All three versions do the same job.
  • Most React code you will read online uses destructuring, so students must recognise it.
  • Common mistake: forgetting the curly braces: function StudentCard(name, course). Then name is the whole props object and course is undefined.

Rule

Props are read-only 🔒

A child component must never change the props it receives.

❌ Don't do this

React may throw Cannot assign to read only property, and even when it doesn't, the parent's data gets out of sync.

✅ Do this

Read the prop and create a new value from it. Want to change the data? The parent changes it and passes new props.

A sealed exam question paper: every student gets the same paper. You read it and write your answers on a separate answer sheet. You don't cross out the questions and write new ones! Only the examiner (the parent) can change the paper.

  • Why the rule? A component should give the same output for the same props, like a calculator: 2 + 3 is always 5. That makes apps predictable.
  • So how does data change on screen? With state, which comes in Class 7. Props = data from outside; state = data a component owns.

Common mistakes

⚠️ Props mistakes to avoid

❌ Mistake What happens ✅ Fix
function Card(name) name is the whole props object function Card({ name })
<Card Name="Arun" /> but reading name Nothing shows (props are case-sensitive) Use the exact same spelling
age="20" then {age + 1} Shows 201 age={20}
skills="HTML, CSS" then skills.join() Error: join is not a function skills={["HTML", "CSS"]}
props.name = "New" inside the child Error or confusing bugs Props are read-only. Make a new variable
Passing props to a component that doesn't read them Nothing happens Destructure every prop you need
