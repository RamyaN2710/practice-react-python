Class format

The 60-minute blueprint

Every deck follows the same rhythm, so students always know what comes next.

  1. 0–10
    🎯 Hook and recapA real-life question or demo, plus a quick look back at the last class
  2. 10–25
    🧠 Concept + analogyEvery idea is tied to something from daily life
  3. 25–40
    💻 Live codingEdit the live playground in the slides or work in VS Code
  4. 40–52
    🧪 Student exerciseStarter code with TODOs is ready in the slides
  5. 52–60
    ✅ Quiz, recap, To PracticeClickable quiz with confetti, flip-card recap and To Practice

Why real-life examples?

Beginners remember stories better than syntax. A component is a cookie cutter, props are a coffee order, state is a cricket scoreboard and an API is a restaurant waiter. Each concept gets one memorable picture.

The weekly checkpoints are quick tests. Before moving on, ask 3 students to explain a checkpoint item in their own words.
