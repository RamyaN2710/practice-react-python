Definition

What is JavaScript?

JavaScript is a programming language that makes web pages interactive. It is the only programming language that runs in every web browser.

  • Created in 1995 by Brendan Eich, in about 10 days
  • Runs in Chrome, Edge, Firefox and Safari, on phones and laptops
  • With Node.js, it also runs on servers
  • It is the base for React, Angular, Vue and many more
☕ ≠ 📜

JavaScript is not Java!

They are completely different languages. As the joke goes, "Java is to JavaScript what car is to carpet." 😄

If a web page is a body, HTML is the skeleton, CSS is the skin and clothes, and JavaScript is the brain and muscles that let it think and move.

The car/carpet joke usually gets a laugh and helps students remember that Java and JavaScript are unrelated.

Where does JS run? · 10–20 min

Every browser has a JavaScript playground built in 🖥️

1️⃣Open Chrome or Edge on any page
2️⃣Press F12, or Ctrl+Shift+J (Mac: Cmd+Option+J)
3️⃣Click the Console tab, type the commands on the right and press Enter

The console is like a calculator that understands English-like commands. Type something, press Enter, and get an answer straight away.

  • Do this live. Open the console in a new tab and type each line. Let students do it on their own laptops at the same time.

Variables

A variable is a labelled box

It has a name (the label) and a value (what's inside).

Your tiffin box with your name written on it. The name stays the same, but what's inside can change every day: idli on Monday, biryani on Friday!

Keyword Can change? Real-life example
let ✅ Yes Your phone balance 📱
const ❌ No Your date of birth 🎂
var ⚠️ Old way Don't use it in new code
Rule of thumb for beginners: use const by default, and let when the value needs to change. Mention var only so they recognise it in old tutorials.

Operators · 35–45 min

Operators: JavaScript can do maths ➕➖✖️➗

Operator Meaning Example Result
+ Add 15 + 20 35
- Subtract 100 - 30 70
* Multiply 15 * 3 45
/ Divide 100 / 4 25
% Remainder 10 % 3 1

% (remainder): share 10 sweets among 3 friends. Each friend gets 3, and 1 sweet is left over. So 10 % 3 is 1.

🤯 Guess the output

"5" + 2 → "52". With a string, + joins instead of adding!

5 + 2 → 7. Two numbers are added normally.

"Hi " + "Arun" → "Hi Arun". Joining strings is called concatenation.

Students guess each blurred answer before you click it. "5" + 2 surprises almost everyone. It is a great "aha" moment about data types.

Joining text the easy way

Template literals: fill-in-the-blanks ✍️

Use backticks ` ` and ${ } to put variables inside text.

A wedding invitation template: "Dear ${guestName}, you are invited…". The same card, filled with a different name for every guest.

The backtick key is usually under Esc, at the top-left of the keyboard. Show it physically, because many students can't find it. You can even do maths inside ${ }.

Watch out

Common beginner mistakes 🚧

Forgot the quotes

let name = Priya;

Error: Priya is not defined. Text needs quotes: "Priya"

Wrong capital letters

Console.Log("hi")

JS is case-sensitive. It must be console.log.

Changing a const

const pi = 3.14; pi = 3;

Error: Assignment to constant variable. Use let if it needs to change.

Quotes instead of backticks

"Hi ${name}"

Prints ${name} literally. Template literals need backticks: `Hi ${name}`

String + number surprise

"10" + 5

Gives "105", not 15. Check your data types!

Using it before creating it

console.log(score); let score = 5;

Create the box first, then use it.

Paste one of these into the playground on slide 15 to show the real error message. Learning to read errors calmly is a key skill.
Recap · 55–60 min

⚡ Quick quiz

1. Which keyword should you use for a value that never changes?

✅ const stands for constant, a value like your date of birth.

2. What does "5" + 2 give?

✅ With a string, + joins the values together: "5" and 2 become "52".

3. What is the type of true?

✅ boolean: only true or false, like a light switch. (But "true" in quotes is a string!)

Take a show of hands for each option first, then click.
