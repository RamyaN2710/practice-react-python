🛟 Part A · Advanced Python · 00–12 min

When things go wrong

UPI says "payment failed", IRCTC says "server busy". Good programs don't crash: they handle errors.

Ask: "What happens if an app crashes every time the network drops?" Nobody would use it. Exception handling is what makes software feel reliable.

raise and your own exception classes 💳

🙋 EAFP "Easier to Ask Forgiveness than Permission"
try: x = d["key"] except KeyError: ...
Just try it, handle the failure. The Pythonic style.
👀 LBYL "Look Before You Leap"
if "key" in d: x = d["key"]
Check first. Fine, but racy for files and networks (things change between check and use).
  • Custom exceptions should inherit from Exception (not BaseException). Give them useful attributes like shortfall.
  • Never write a bare except:: it also swallows Ctrl+C and typos. Catch specific exceptions.

Files · 12–20 min

Reading & writing files with with 📂

The browser's Python has a pretend disk, so this really creates a file.

"r" "w" "a"
read · write (overwrite) · append. Add "b" for binary (images, PDFs).
Why with?
It closes the file automatically, even if an error happens inside.

A hotel key card: pull it out and the AC and lights switch off by themselves. You can't forget.

Without with you need f = open(...) … f.close() inside a try/finally. Interview question: "Why use with?" → automatic cleanup, even on exceptions.
Live code · write your own with

Custom context managers 🔌

Two ways: a class with __enter__/__exit__, or a generator with @contextmanager.

  • Code before yield = __enter__; code after (in finally) = __exit__.
  • Real uses: DB connections, locks (with lock:), temporary directories, timing blocks.
  • If __exit__ returns True, the exception is swallowed. Rarely what you want.
Iterators · 20–32 min

Iterable vs iterator 🔁

📚 Iterable
Anything you can loop over: list, str, dict, file. Has __iter__.
🔖 Iterator
Remembers where you are. Has __next__; raises StopIteration at the end. Used up after one pass.

A book is iterable. A bookmark is the iterator: it knows your page, and moves forward one page at a time.

A for loop secretly calls iter() once, then next() until StopIteration.

Writing __iter__ + __next__ by hand is tedious. Next slide: generators do all of it with one keyword, yield.

Generators: compute only when asked 🪶

Generator expression = list comprehension with ( ). Perfect inside sum(), max(), any(): sum(x*x for x in nums).

The browser runs 32-bit Python, so sizes are about half of your laptop's (~8 MB list vs ~200 bytes).

Real use: processing a 10 GB log, CSV or database export without loading it all into RAM. Interview line: "Generators are lazy: they trade one-time-use for O(1) memory."

Concurrency · 48–52 min · interview favourite

The GIL and the Swiggy kitchen 🍳

GIL (Global Interpreter Lock): in CPython, only one thread runs Python code at a time, like a kitchen with one gas stove.

🧵

threading

Many cooks, one stove. While one waits for the delivery partner, another cooks.

I/O-bound
🏭

multiprocessing

Open 4 separate kitchens, each with its own stove (own GIL). True parallel, but costs more.

CPU-bound
⚡

asyncio

One super-waiter: takes table 1's order, and while it cooks, serves table 2. Never stands idle.

Lots of I/O

I/O-bound = mostly waiting: API calls, downloads, DB queries, reading files.

CPU-bound = mostly calculating: image resizing, encryption, big maths loops.

  • Why does the GIL exist? It makes reference counting (memory management) simple and safe.
  • Threads release the GIL while waiting on I/O, so threading still speeds up downloads.
  • Bonus: Python 3.13 added an experimental "free-threaded" build without the GIL (PEP 703).
Code you'd write on your laptop (not in the browser)

Which tool for which job? 🧰

Parallel CPU? Best for
threading ❌ (GIL) Few I/O tasks, simple code
multiprocessing ✅ yes CPU-heavy work on all cores
asyncio ❌ one thread Thousands of network calls (FastAPI, bots)
Easy mode: concurrent.futures (ThreadPoolExecutor / ProcessPoolExecutor).
These are static: the browser's Python can't start real threads or processes. Interview one-liner: "Threads for I/O, processes for CPU, asyncio for massive I/O with one thread."
Internals · 52–55 min

How Python frees memory 🧹

1️⃣ Reference counting
Every object counts the names pointing at it. Count hits 0 → freed immediately.
2️⃣ Garbage collector
Finds cycles (A → B → A) that refcounting can't free. Module gc.
3️⃣ Interning
Small ints -5 to 256 and many short strings are cached and shared. Never rely on is for numbers!

Refcount is a stadium seat: the cleaner removes it when the last fan leaves. Two friends holding each other's seat forever? The GC usher clears them.

Exact getrefcount numbers vary between Python versions; the point is it goes down by one after del. All of this lives on Python's private heap, managed by the interpreter.

🎯 Rapid-fire · round 1 · 30 seconds each

Answer out loud, then reveal ⚡

List vs tuple?

List is mutable [ ]; tuple is immutable ( ), slightly smaller and faster, and hashable (if its items are), so it can be a dict key. Tuples for fixed records.

Shallow vs deep copy?

copy.copy makes a new outer object but shares the inner objects. copy.deepcopy copies everything recursively. Matters for nested lists/dicts.

What are *args and **kwargs?

They collect extra positional arguments into a tuple and extra keyword arguments into a dict. Used in wrappers/decorators to pass everything through.

What is a decorator?

A function that takes a function and returns a new one with extra behaviour, without changing its code. @d above def f means f = d(f). Uses: logging, timing, auth, caching.

Generator vs iterator?

An iterator is any object with __iter__ and __next__. A generator is an easy way to make one, using yield. Every generator is an iterator, not vice versa.

What is the GIL?

A lock in CPython that lets only one thread run Python bytecode at a time. Threads still help for I/O; use multiprocessing for CPU-bound work.

__init__ vs __new__?

__new__ creates and returns the object (gets cls, runs first). __init__ initialises it (gets self, returns None). Override __new__ for singletons.

@staticmethod vs @classmethod?

classmethod receives the class (cls): great for alternative constructors like from_string(). staticmethod receives nothing: a plain function kept inside the class.

Point at a student, read the question, count to 30. Reveal only after they try. Push for the definition → example → trade-off structure.
🎯 Rapid-fire · round 2

Keep going! ⚡⚡

is vs ==?

== compares values; is compares identity (same object). Use is only for None/True/False.

Why is a mutable default argument dangerous?

Defaults are created once, when def runs, so def f(x, items=[]) shares one list across calls. Use items=None and create the list inside.

What is pickling?

Turning a Python object into bytes (pickle.dumps/dump) and back (loads/load). Used to save models and caches. Never unpickle untrusted data: it can run code.

Limitations of lambda?

Only one expression: no statements (loops, try, normal assignment), no docstring, and it shows up as <lambda> in tracebacks. Use def for anything bigger.

What is a context manager?

An object with __enter__/__exit__ used with with. It guarantees cleanup (close file, release lock, close DB) even if an exception happens.

How does Python manage memory?

A private heap managed by the interpreter. Reference counting frees objects at count 0; a cyclic garbage collector cleans reference cycles. Small ints/strings are interned.

What does if __name__ == "__main__": do?

Its block runs only when the file is executed directly, not when it is imported. Keeps test/demo code from running on import.

__str__ vs __repr__?

__str__: readable, for users (print). __repr__: unambiguous, for developers (REPL, debugging). If __str__ is missing, __repr__ is used.
