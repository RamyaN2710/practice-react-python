Concept · 05–15 min

What is JSX? ✍️

JSX lets us describe what the UI should look like using syntax that resembles HTML inside JavaScript.

  • JSX = JavaScript + XML (HTML-like tags)
  • It looks like HTML, but it is not HTML
  • The browser can't read JSX directly. Vite (with Babel) converts it to plain JavaScript
  • Because it is JavaScript, we can mix in variables and logic

JSX rule 1

Use className, not class 🏷️

❌ HTML habit

class is a reserved word in JavaScript (used for making classes), so JSX can't use it.

✅ JSX way

The CSS stays the same: .card { ... } in your CSS file still works.

Two players with the same name: if a cricket team already has a "Rohit" as captain, the new Rohit gets called "Ro" on the field to avoid confusion. JavaScript already uses the word class, so JSX calls it className.

Show the playground from the previous slide: it already uses className="card". Tip: VS Code with the React snippets extension autocompletes className for you.
JSX rule 2 · 25–35 min

Return one root element (or a fragment) 🎁

🍚 🍛 🥗 → 🍱

Pack everything in one tiffin box

Your mom doesn't send rice, curry and salad as three loose plates. She packs them into one tiffin box.

A component must return one thing. A <div> is a real box. A fragment <></> is an invisible box: it groups things but adds nothing to the page.

  • Click through the three tabs. On the first tab, read the real error message aloud. Students will see it often.
  • Why the rule? Remember createElement: a function can only return one value.
  • When to use which: fragment when you don't need styling, div when you want a className on the wrapper.
JSX rules 3–5

Three more rules to remember 📏

🔒

Close every tag

Even tags that are "empty" in HTML must close with />.

<img src="a.png" />
<br /> <input />

🐫

camelCase attributes

Two-word attributes join with a capital letter.

onclick → onClick
for → htmlFor
tabindex → tabIndex

🧮

Expressions, not statements

Braces need something that gives a value.

✅ {isMember ? "Gold" : "Free"}
❌ {if (isMember) { ... }}

Expression vs statement: an expression is like a calculator answer: "₹120 × 3" gives 360, which you can write on the bill. A statement is like an instruction: "if it rains, take an umbrella". You can't write an instruction on the bill. Braces want an answer.

  • For the expression rule, ask: "Does it produce a value I can print?" If yes, it can go in braces.
  • Put the if above the return (outside JSX) or use the ternary inside. We'll practise this properly in Class 8.

Common mistakes

⚠️ JSX mistakes everyone makes (once!)

❌ Mistake ✅ Fix Why
<p>Hello name</p> <p>Hello {name}</p> Without braces it is plain text
<img src={photo} alt="me"> <img src={photo} alt="me" /> Every tag must close
<div class="box"> <div className="box"> class is reserved in JS
Two tags side by side in return Wrap in <div> or <> </> Return only one root
{student} where student is an object {student.name} React can't print a whole object
